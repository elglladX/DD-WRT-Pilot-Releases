# DD-WRT Pilot

**DD-WRT Pilot** is a modern Android application designed to make managing DD-WRT routers easier, faster, and more convenient.

Whether you want to monitor your router, manage connected devices, control wireless settings, run commands, or keep an eye on your network, DD-WRT Pilot brings essential DD-WRT tools together in one place.

## Features

- **Router Profiles**  
  Save and manage multiple DD-WRT router configurations.

- **SSH Router Control**  
  Connect to your router securely and execute supported commands.

- **Real-Time Router Statistics**  
  Monitor system information, uptime, CPU, memory, network interfaces, and other router statistics.

- **Connected Devices**  
  View devices connected to your network and manage supported device actions.

- **Wireless Controls**  
  Monitor and control supported wireless interfaces and settings.

- **Traffic Monitoring**  
  Keep an eye on network traffic and interface activity.

- **Wake on LAN**  
  Wake supported devices on your network remotely.

- **Access Restrictions**  
  Manage supported access-control and blocking features.

- **NVRAM Management**  
  View and manage supported DD-WRT NVRAM parameters.

- **Firmware Management**  
  Check for compatible firmware versions and manage supported firmware upgrades.

- **Backup & Restore**  
  Create and restore supported DD-WRT configuration backups.

- **Network Diagnostics**  
  Run useful network and connectivity diagnostics directly from the app.

- **Custom Terminal Commands**  
  Execute custom commands when you need more control.

- **Feedback & Support**  
  Send feedback and report issues directly from the application.

## Compatibility

DD-WRT Pilot is designed specifically for devices running **DD-WRT firmware**.

Compatibility may vary depending on the router model, DD-WRT version, available features, and configuration.
